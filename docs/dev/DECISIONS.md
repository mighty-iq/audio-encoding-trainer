- 2026-11-26 Learner model: product of per-dial logistic components (each dial a bottleneck) rather than an additive logit, because per-dial abilities are not identifiable in an additive model; known limit: a secondary dial still limits accuracy when the primary dB dial is very easy (fix candidate: per-level costs once pooled data exist). Reason: engine builder's simulations.
- 2026-11-26 Each trial updates only its focus dial's posterior; updating the others let confounded estimates drift below their easiest level. Reason: engine simulations.
- 2026-11-26 Plateau rule as implemented: window of 6 sessions (≥ 80 scored trials, ≤ 12 sessions), focus-weighted index, residual SD floor 0.35 dB-eq, slope prior N(0, 0.5²); "flat" = 80 % upper bound of the slope < +0.15 dB-eq per session for 3 windows in a row, plus no personal best in 4 sessions, and ≥ 3 sessions between breakers. The plan's two-sided "within ±0.15" can never fire with six sessions of training data, so only the upper bound is used. Simulated: catches 61 % of flat stretches (median 8 sessions after the stall), false alarms 11–16 % for learners improving right at the band edge, 0–2 % for clearly improving ones. Reason: engine simulations; target < 10 % at the edge not yet met (open).
- 2026-11-26 Personal bests are per dial (≥ 0.10 logit beyond the best), in real units; breadth (variety) is judged on edge trials only; the distance ladder tops at 30 m and the room always fits the distance (§12 R1). Reason: engine design.
- 2026-11-26 Held-out degradation family for the New-voice probe: tone-vocoded speech; the engine never generates it in training. Reason: keeps the probe untrained.
- 2026-11-26 Lab weekly check-in runs Matrix twice by default until its verdict is clear (cap 8 check-ins), because one run a week reached a clear verdict for a true 1.5 dB gain in only 56 % of simulated players by week 4 versus 79 % with two runs (false clear 2 % either way); the Two-voices probe (run SD ≈ 1.9 dB) is kept for longer trends and pooled data. Reason: the standing rule that a real gain becomes visible within weeks.
